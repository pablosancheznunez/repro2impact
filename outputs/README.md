# Outputs · data dictionary

Generated by `targets::tar_make()`. CC BY 4.0. Altmetric and Overton values are not redistributed.

## `articles.csv`: one row per sampled article

| Column | Meaning |
| --- | --- |
| `doi`, `openalex_id` | Identifiers |
| `stratum`, `year`, `cell` | Sampling field, publication year, and field × year |
| `journal`, `issn_l`, `source_id` | Journal (OpenAlex source) |
| `oa_status`, `is_oa` | Open access status (OpenAlex) |
| `n_authors`, `n_institutions`, `n_countries`, `international`, `n_references`, `funded` | Covariates |
| `cit_5y` | Citations in years +1 to +5 after publication (OpenAlex `counts_by_year`); NA if the window is incomplete |
| `cit_norm` | `cit_5y` divided by the mean of its field × year cell in the sample |
| `fwci` | OpenAlex field-weighted citation impact (external comparison) |
| `wikipedia` | English and Spanish Wikipedia articles whose source contains the DOI |
| `fulltext_source` | `europepmc`, `oa_landing` or `unavailable` |
| `data_statement`, `data_shared`, `code_shared`, `preregistered`, `materials_shared` | `yes`, `no` or `unverifiable` |
| `*_evidence` | Sentence (≤ 400 characters) or metadata link supporting a `yes` |
| `detector_version` | Version of the rules in `R/detect.R` |

## Other files

| File | Content |
| --- | --- |
| `prevalence.csv` | Prevalence by indicator, field and year: `yes`, `n_verifiable`, `n_unverifiable`, Wilson 95% CI |
| `associations.csv` | Rate ratio per indicator and outcome. `method` is `nb_glmm`, `hurdle_nb` or `psm`; also 95% CI, `p`, Holm-adjusted `p_holm` (confirmatory tests only), E-values and `max_smd` after matching |
| `heterogeneity.csv` | Exploratory rate ratios by field, open access status and collaboration |
| `weight_sensitivity.csv` | Rate ratio per SD of a composite under random weights. This is a sensitivity analysis only, never a score |
| `linked_objects.csv` | Datasets and software linked in DataCite, with their citations, views and downloads |
| `reuse.csv` | Reuse of linked objects by type (among sharers only) |
| `coding_sheet_*.csv` | Blank manual coding sheets for the codebook |
