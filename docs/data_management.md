# Lista de gestión de datos

- [ ] Fuente, consulta exacta, fecha y versión registradas
- [ ] Licencia y redistribución registradas para cada fuente
- [ ] Deduplicación de identificadores y exclusiones documentadas
- [ ] Datos brutos en ubicación institucional aprobada; sin credenciales en el repositorio
- [ ] Evidencia de codificación almacenada separada de la tabla pública
- [ ] Los códigos desconocidos permanecen `unclear`; no se convierten en ausencia
- [ ] Revisión de privacidad/datos personales con la unidad institucional competente
- [ ] Publicación revisada contra las licencias de cada fuente
